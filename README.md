# BODMAS Experiment 1: error position

Can people tell which order-of-operations misconception a student holds from the student's written
work, and does it matter whether the error happens at step 1 or step 3?

This repo contains:

- `base-task/`: the learner model, the 240-item stimulus pool (`stimulus_pool.json`), its builder
  and verifier, and a Bayesian ideal observer run over the pool.
- `analysis-Bayesian/`: ideal-observer figures.
- `src/`: the web experiment, built on [Smile](https://smile.gureckislab.org/) (codec-lab fork).

**Start with [`HANDOFF.md`](HANDOFF.md)**, the full orientation: setup, design, results so far, and
what is next.
